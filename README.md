# Диковерия LAB — Android (пакет исходников 0.3.0-dev)

**Статус:** разработка, НЕ подтверждённый к эксплуатации готовый APK. Исходники подготовлены, модель и SQL проверены локально; Android-компиляция должна пройти GitHub Actions после загрузки проекта. Полный перечень реализованного и оставшихся работ — [docs/IMPLEMENTATION_REPORT.md](docs/IMPLEMENTATION_REPORT.md).

## Что делает код сейчас

- локальная SQLite-база с транзакциями и миграцией из прототипа базы версии 1;
- каталог видов/сортов и независимых маточников, контейнеры и журнал действий;
- пересадки с сохранением родительской связи, исходного и полученного количества;
- осмотры и отдельные количественные измерения, статусы и карантин;
- рецепты питательных сред, компонентный калькулятор, версии, партии и фактические дозировки;
- CSV-обмен рецептами (Excel / Google Sheets с ручным экспортом в CSV);
- базовая аналитика сред, культур и выручки;
- QR-коды, сканирование камерой, экспорт изображения этикетки;
- фотографии, задачи, склад, оборудование, инциденты, эксперименты, продажи;
- ручные полные ZIP-резервные копии (база + фотографии) с транзакционным восстановлением.

**Нет автоматической синхронизации с Google Sheets, автоматического резервного копирования в Drive, прямой Bluetooth-печати NIIMBOT, многопользовательского сервера, интеграции с продажами, ИИ-аналитика.** Некоторые утверждённые процедуры реализованы только частично. Не использовать этот пакет как завершённую производственную систему.

## Технологии

Kotlin 2.0.21, Android Gradle Plugin 8.7.3, Gradle 8.9, Java 17, Android compileSdk 35 / minSdk 26, Jetpack Compose Material 3, SQLiteOpenHelper, ZXing. Пакет проекта сохраняет `applicationId=ru.dikoveriya.lab`; `versionCode=3`.

## Как загрузить проект

**Без ручного изменения каждого Kotlin-файла:** см. [docs/INSTALL_GITHUB.md](docs/INSTALL_GITHUB.md). В комплекте лежит готовый GitHub Actions workflow. После загрузки всех файлов он запускает тесты и сборку APK.

## Научная осторожность

В коде нет якобы универсальных дозировок для Babio MS, 6-БАП, NAA, IBA, поскольку точные применимые концентрации требуют подтверждения по этикетке и протоколу. Пример CSV — демонстрация формата, **не рецепт для применения**. Готовая смесь с агаром и сахарозой должна помечаться в рецепте, чтобы избежать случайного двойного добавления.

## Состав

- `app/src/main/java/ru/dikoveriya/lab/LabDatabase.kt` — схема, миграции, транзакции и доменные операции.
- `LabModels.kt` — данные и лабораторный калькулятор.
- `RecipeCsv.kt` — CSV-разбор и правила ввода.
- `LabBackup.kt` — ZIP-экспорт и восстановление вместе с фотографиями.
- `LabQr.kt` — QR-код и изображение PNG.
- `MainActivity.kt` — навигация, Android file picker, сканер.
- `LabForms.kt`, `UiBasics.kt` — пользовательские формы и помощь «?». 
- `app/src/test` — JUnit-тесты рецептур и CSV.
- `qa` — офлайн-проверки модели и SQLite.

## Резервирование

Путь: «Ещё» → «Резервные копии». Копию ZIP необходимо регулярно сохранять **вне телефона**. Выгрузка не шифруется; не публиковать её в открытом доступе. Автоматический облачный бэкап пока не настроен; Android Auto Backup отключён, чтобы не восстанавливать фото отдельно от базы.

## Работа с рецептами из Excel

«Ещё» → «Питательные среды» → «Экспорт CSV». Отредактируй файл в Excel либо Google Sheets, сохрани/экспортируй **UTF-8 CSV с разделителем `;`**, затем «Импорт CSV». Импорт не перезаписывает действующие протоколы; он создаёт новую версию **в статусе черновика**, которую надо проверить и утвердить. Самообновление из Google Sheets не реализовано.

## Подпись APK

GitHub Actions без настроенных секретов использует временный debug-ключ, и следующая сборка может **не установиться поверх предыдущей**. Для долгосрочной работы настрой постоянную подпись из GitHub Secrets (`LAB_KEYSTORE_B64`, `LAB_KEYSTORE_PASS`, `LAB_KEY_ALIAS`, `LAB_KEY_PASS`). Не публикуй свой `.jks` в открытом репозитории. Инструкция в `docs/INSTALL_GITHUB.md`.
