# Диковерия LAB 0.4.0-dev — первый этап лабораторного учёта

Исходный код Android-приложения. **Версия 0.4.0-dev не объявляется полностью готовой к промышленной эксплуатации**, пока GitHub Actions не подтвердит сборку APK и не пройдёт тестирование операций на телефоне.

## Что добавлено в 0.4.0-dev

- «Что произошло?» в карточке контейнера: разделение на 1–25 дочерних контейнеров, частичная пересадка, объединение 2–25 источников того же вида/сорта, списание потерь, учёт аварий, исправление ошибочного количества, аннулирование ошибочно созданного контейнера и безопасная отмена последних действий.
- Контроль остатка исходного материала и отдельный учёт израсходованных объектов, новых побегов/растений и реальных потерь.
- Объединение ведёт многостороннее происхождение. Если происхождение не подтверждено, помечается как смешанное или неизвестное, а программа требует подтверждения риска.
- Журнал операций с фактической датой и датой внесения записи. Отмена возможна только при отсутствии последующих действий с затронутыми контейнерами; история не удаляется.
- Происшествия связываются с несколькими контейнерами, могут переводить их на контроль или карантин; последующие решения и завершение регистрируются отдельно.
- Категория учёта количества: экспланты, побеги, растения, не уточнено.
- База данных версии 5 с неразрушающей миграцией версии 4. Ручные ZIP-копии поддерживают восстановление экспортов схем 4 и 5 (фото + база).

## Запуск тестов

```bash
bash qa/run_model_tests.sh
```

Android-юнит-тесты и сборка: `gradle :app:testDebugUnitTest :app:assembleRelease` внутри GitHub Actions. Подпись release APK **только постоянным ключом**. Ожидаемый SHA-256 сертификата проверяется workflow.

## Важно

- Нет автоматической Google Sheets/Drive синхронизации, прямой Bluetooth-печати NIIMBOT D11 и промышленных прогнозов.
- Аналитика питательных сред остаётся предварительной; повторные наблюдения одной культуры нельзя трактовать как независимые экспериментальные повторности.
- Операции до этой версии (из 0.3) сохраняются, но автоматически отменять их через новый журнал нельзя: у них отсутствовали сведения для безопасного отката.
- Не удаляйте приложение перед обновлением: версияCode `40000 + GITHUB_RUN_NUMBER` выше прежней подписанной ветки. **Ключ подписи должен остаться тем же.**
