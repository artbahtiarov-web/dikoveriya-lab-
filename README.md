# Диковерия LAB

Android MVP 0.1.0. **Демонстрация без подключения к Google Sheets.** Контейнеры существуют только пока приложение открыто; после перезапуска данные пропадают. Не используйте для реального лабораторного учёта.

## Функции 0.1
- Главный экран и число активных контейнеров
- Создание демонстрационного контейнера из трёх растений
- Карточка и демонстрационное списание

## Сборка
GitHub Actions -> Build Android APK -> Run workflow. После успешной сборки скачайте artifact `dikoveriya-lab-debug-apk` (ZIP), распакуйте и установите `app-debug.apk` на Android 13.

## Обновления
Для следующих версий потребуется постоянный ключ подписи release APK. Debug APK пока только для тестирования.

## План
1. Локальное постоянное хранение и журнал событий
2. Google OAuth и подключение Google Sheets
3. Пассажи, осмотры, отсрочки, QR, NIIMBOT D11
4. Бэкапы, протоколы, аналитика
