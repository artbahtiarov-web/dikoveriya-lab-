# Диковерия LAB · обновление 0.6.0-dev

Пакет — **исправление поверх существующего проекта 0.5**, не самостоятельный APK.

Установочный архив переименован в `dikoveriya-lab-update.zip`, чтобы существующий GitHub Actions автоматически принял его **без замены workflow**. Он содержит `apply_v050.py` (совместимость по имени), `qa/check_v050.py` (новая проверка версии 0.6), три Kotlin-файла логики и дизайна. Патч строго проверяет исходные строки; при несовпадении прекращает работу без выпуска APK.

Введено:

- Встроенное добавление вида/сорта, маточника и среды в форме нового контейнера.
- Создание **готовой рецептуры одним действием** — с названием, назначением, растением, объёмом, компонентами и их количествами. Готовый рецепт можно выбрать без дублирования.
- Прямое привязывание версии рецептуры к контейнеру, без обязательного этапа приготовления партии.
- Независимый ввод эксплантов, побегов и растений. Первое измерение записывается автоматически.
- Указание массы уже включённого сахара и агара, проверка возможного двойного добавления.
- Новая база v7, журнал наблюдений и смен сред, сохранение версии рецептуры каждого наблюдения.
- Отчётность по культурам: выручка по продажам, количество контейнеров и последние зарегистрированные показатели. Это не прибыль и не статистически доказанная эффективность рецепта.
- Единый интерфейс на утверждённой спокойной палитре: обновлены общая тема, карточки, заголовки, метрики и иконка в заголовке. Существующий launcher-значок сохранён.

Технические ограничения: проверка в Android SDK/GitHub Actions и на физическом телефоне необходима после загрузки пакета. Не удаляйте установленное приложение. Перед обновлением сделайте резервную копию в приложении. Рецептуры и рост не подставляются из неподтверждённых научных источников.

Внимание: в старом режиме расширенной рецептуры есть контрольные переключатели сахара/агара без количественных полей — использовать новый единый редактор для новых рецептур. Ранее сохранённые «уже содержит» без величин в граммах остаются помечены как количественно неизвестные.
