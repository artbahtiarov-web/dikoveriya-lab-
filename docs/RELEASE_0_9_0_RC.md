# Диковерия LAB — 0.9.0-rc1 (тест прямой печати NIIMBOT)
Дата: 2026-11-13 UTC. Основание: Issue #19 и замечания после установки 0.8.0.

## Изменения в исходниках
- Выбор элемента на холсте; физическое изменение размера за четыре угловых маркера с областью касания 48dp, а также ±10%, двумя пальцами. Перемещение одним пальцем, фиксация, Undo/Redo. Масштаб предпросмотра — отдельная настройка.
- 28 отдельных свободно распространяемых OFL-семейств с кириллицей. Шрифты скачиваются из закреплённой ревизии Google Fonts на этапе сборки, проверяются Git blob SHA, включаются в APK вместе с лицензиями. Автономная работа после установки.
- Форматирование выбранного текстового элемента целиком: жирный (B), курсив (I), подчёркивание (U) и все сочетания. Межбуквенный интервал, выравнивание, поворот. Предпросмотр и экспорт используют один рендерер Android.
- Обратная совместимость старых сохранённых макетов JSON v1 из 0.8.0: новые поля по умолчанию выключены, новый формат сохраняется как JSON v2. SQLite v10 не меняется. Номер и QR контейнера обязательны.
- Нативный Bluetooth BLE: поиск NIIMBOT, определение model ID и dpi, приём уведомлений и командные пакеты, преобразование изображения 40×12 мм под печатающую головку, отправка, контроль результата по ответу принтера. Отдельные настройки плотности, подачи и копий.
- Массовая очередь из списка контейнеров: максимум 200 разных записей с собственными QR и сохранёнными шаблонами; генерация PNG по одному объекту. Android Share и PNG сохранены как запасные способы, НЕ как прямая печать.

## Источники для NIIMBOT
- https://printers.niim.blue/interfacing/print-tasks/
- https://printers.niim.blue/hardware/models/
- https://github.com/iscarelli/niimbot-web-bluetooth/blob/main/docs/protocol-v4.md
Параметры task и BLE, извлечённые из community reverse-engineering, не заменяют аппаратную проверку нужной ревизии.

## Аппаратная приёмка — обязательный блокер стабильной версии
1. Узнать реальную модель, dpi и firmware после соединения. Неизвестную модель отклонять.
2. Пробная бумажная этикетка 40×12 мм. QR читается, идентификатор совпадает, текст не обрезан, ориентация верна.
3. Печать после изменения размера текста/QR, применения семейства с кириллицей, B+I+U.
4. Очередь 10 разных контейнеров: сверить 10 разных QR, статус завершения, отсутствие дублирования.
5. Проверить обрыв BLE, отказ разрешений и остановку; результаты, которые принтер не подтвердил, обозначать как неизвестные и не повторять автоматически.
6. Обновление поверх установленной 0.8.0, сохранность базы, шаблонов и резервной копии.

**Нельзя заявлять стабильный 0.9.0 по одним CI-тестам.** До аппарата и проверки пользователя доступен только подписанный 0.9.0-rc1 для тестирования.

## Проверки и безопасность
- PR QA: Python/SQLite, :app:testDebugUnitTest, :app:assembleDebug, Android instrumented при 360/430dp и увеличенных шрифтах.
- В CI тестируются сохранение JSON v1→v2, B/I/U, 28 семейств, размеры, QR, байтовые кадры NIIMBOT, контроль ответов и ориентация растровых строк.
- Signed RC workflow отдельно проверяет **постоянный** сертификат (SHA256), аналогичный 0.8.0. Debug APK не использовать для обновления подписанной версии.
- Android applicationId и ключ не меняются. SQLite остаётся v10. История операций, среды, наблюдения и биологические единицы не переписываются.

## Ограничения
- Прямая печать на устройстве пользователя и на его прошивке пока не подтверждена.
- B/I/U применяются к целому текстовому элементу; выделение произвольных подстрок не реализовано.
- Фактические параметры плотности и смещения требуют проверки на бумаге. Экспериментальная модель может отказать.
