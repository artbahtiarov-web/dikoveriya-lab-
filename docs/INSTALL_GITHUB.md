# Установка обновления 0.4.0-dev через GitHub (без ручного редактирования Kotlin)

В этой версии по-прежнему используется **постоянный ключ**, уже сохранённый в GitHub Secret `LAB_SIGNING_BUNDLE_B64`. **Не создавай новый ключ и не загружай существующий приватный ключ в репозиторий.**

1. Сначала в приложении 0.3 открой «Ещё» → «Резервные копии» → «Сохранить копию» и сохрани ZIP в безопасном месте вне телефона.
2. В GitHub открой `.github/workflows/build-apk.yml`, нажми карандаш, замени весь файл содержимым одноимённого **полного** файла `build-apk-stage1.yml`, который выдан вместе с архивом, и нажми `Commit changes`.
3. Открой главную страницу `artbahtiarov-web/dikoveriya-lab-`, выбери `Add file` → `Upload files`. Загрузи **один архив** `dikoveriya-lab-update.zip` в корень репозитория. Не распаковывай. Нажми `Commit changes`.
4. На странице `Actions` проверь запуск, начавшийся **после загрузки ZIP**. На шаге `Apply complete source update` архив будет распакован; workflow попробует записать исходники в репозиторий. Если запись разрешена, исходники появятся в main. Если нет — APK всё равно попытается собраться из распакованной копии, но репозиторий придётся обновить отдельно.
5. После **зелёной** сборки найди Artifacts → `dikoveriya-lab-signed-release`, скачай ZIP, распакуй `app-release.apk` и установи на телефон **поверх** текущей версии, не удаляя её.
6. После установки открой существующие контейнеры и проверь, что они сохранились, затем создай **тестовую** операцию и проверь историю/остатки.

**Если GitHub пишет про отсутствующий секрет или другой сертификат — не удаляй старое приложение.** Сначала нужна диагностика подписи.

**Если появляется конфликт пакета при установке:** остановись, не удаляй приложение с данными. Проверяются сертификаты старой и новой APK и версияCode.

## Что делать, если сборка красная

Пришли ссылку на конкретный GitHub Actions job. Причину определяем по первой содержательной ошибке (`e:`, `error:` или `FAILURE`), а не подбираем исправления вслепую.

## Альтернатива, если нельзя менять workflow

Установи GitHub Desktop, клонируй репозиторий, распакуй `dikoveriya-lab-update.zip` и скопируй все **полные** файлы поверх клона без затрагивания `.git`. Затем Commit → Push и проверь GitHub Actions. Не загружай секреты, P12/JKS и пароли в публичный репозиторий.
