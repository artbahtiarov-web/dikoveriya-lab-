# Диковерия LAB — дорожная карта до 1.0

Единый источник требований: GitHub Issue #4. Подробный аудит 0.6.0: Issue #3. Более ранние согласованные требования: Issue #1.

## Продуктовые правила
- Один контейнер — одна карточка; главные пути **Рост / Среда / Операции / История**, а также Фото и Этикетка. Все подэкраны сохраняют контекст.
- Навигация стеком: стрелка «Назад» видна, Android Back/жест с обоих краёв возвращает один уровень и не сбрасывает несохранённую форму без предупреждения.
- Каждый раздел — полный экран с поиском, фильтрами, структурированной информацией и понятными действиями; никаких бесконечных однотипных диалогов.
- Стиль: премиальный ботанический, тёплая светлая основа, хвойный primary, акценты по смыслу, крупные иконки, достаточные отступы, доступная контрастность, основные кнопки под большим пальцем. Сигнал не только цветом.
- На главной лаборатории — оперативное состояние и быстрые переходы, а не дублирование всей базы.
